# Granite-type classification workflow

This workflow classifies reported I-, A-, and S-type granite affinity using
source-connected validation and evaluates class-specific SHAP attribution.

Input: `../../data/source/Supplementary_Table_S1.xlsx`. The Geological Groups
worksheet supplies the group metadata used by the classifier.

Run the notebook in `notebooks/`. Saved numerical outputs are in
`../../results/granite_classification/`.
