# Data dictionary

The complete field-level data dictionary is the `Data dictionary` worksheet in
`data/source/Supplementary_Table_S1.xlsx`.

The Dataset worksheet stores record identifiers, sample identifiers, reported
mineralization and granite-type labels, geological-group identifiers, reference
identifiers, major-element oxides, trace elements, and rare-earth elements. Major
elements are reported in wt.% and trace elements and rare-earth elements in ppm.

The Geological Groups worksheet defines group identifiers, group type, grouping
rationale, confidence level, sample count, and source references. It is used for
source-connected validation and replaces the prior standalone group-metadata file.
